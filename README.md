# DrumFeedback

드럼 치는 소리를 마이크로 듣고 지금 몇 BPM인지, 어디서 빨라지고 느려졌는지 알려 주는 웹 도구입니다.

- **설치·설정 없이**: 페이지를 열고 마이크만 허용하면 됩니다. 목표 템포는 비워 둬도 되고, 그러면 처음 4초의 빠르기가 기준이 됩니다.
- **드럼 전용 감지**: 킥·스네어·하이햇 대역별로 타격 순간을 찾아 빠르기를 계산합니다. 30–300 BPM.
- **2배·절반 바로잡기**: 숫자가 두 배나 절반으로 읽히면 ½× · 2× 버튼으로 고칩니다.
- **틀린 숫자 대신 "측정 중"**: 박이 일정하지 않으면 숫자를 보여 주지 않습니다.
- **연습 리포트**: 끝내면 평균·범위·흔들림(%)·안정성 점수와, 기준보다 빨라지거나 느려진 구간을 시각과 함께 보여 줍니다. 3초 넘게 쉬면 다른 연주로 나눕니다.
- **한 화면**: 가운데에 지금 BPM, 그 뒤로 빠르기 선이 아래에서 위로 흘러갑니다. 가운데가 기준이고 오른쪽으로 가면 빠름, 왼쪽으로 가면 느림입니다.
- 소리는 브라우저 안에서만 분석하고 저장하거나 전송하지 않습니다.

합성한 드럼 소리로만 검증했고, 실제 드럼·실제 마이크에서의 정확도는 아직 확인하지 않았습니다.

## 실행

```bash
npm install
npm run dev      # http://localhost:5173
npm test         # 타격 검출·빠르기 추정·리포트 테스트
npm run build    # 타입 검사 + 배포용 빌드(dist/)
```

마이크는 `localhost`나 HTTPS 주소에서만 쓸 수 있습니다.

## 배포 (GitHub Pages)

`.github/workflows/deploy.yml`이 기본 브랜치에 push될 때마다 테스트 → 빌드 → GitHub Pages 배포를 합니다.
저장소 **Settings → Pages → Source**를 **GitHub Actions**로 한 번 바꿔 줘야 합니다.

## 구조

| 파일 | 역할 |
| --- | --- |
| `src/onset.ts` | 소리에서 타격 순간 찾기 (대역별 에너지 변화) |
| `src/tracker.ts` | 타격 간격에서 빠르기 추정, 2배·절반 고르기 |
| `src/engine.ts` | 소리 → 지금 상태(조용함·측정 중·확정·잠깐 놓침) |
| `src/session.ts` | 연습 기록과 리포트 |
| `src/mic.ts` | 마이크 입력 (AudioWorklet) |
| `src/main.ts` | 화면: 숫자, 그래프, 리포트 |
